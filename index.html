How to read this
writers per cell
Each square is the residual stream at one token (column) after one block (row). Units are the things that write into it: MLP neurons (blue), attention heads (orange), token embeddings (green) and Neuronpedia's res-jb SAE features (violet). Click a unit anywhere to open its card. Built by: the few native writes that rebuild the state (OMP over the model's own write vectors; italic = no better than a random rotation of the same dictionary). SAE features: the strongest features in each square. Why: how much each square pushes an objective (the next token, a token rather than another, or one unit's activation), split over its writers; "check" removes a write for real. Steer Δ: add units and see how far each square moves and how the text changes. Descendants: remove one write at one token and follow what it becomes downstream.
